# Digital Check-In

A modern and interactive To-Do List web application built using **HTML, CSS, and JavaScript**.

The project is designed to be more than a basic task list, with a clean dark interface, animations, task priorities, progress tracking, filters, and browser storage.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Edit tasks by double-clicking
- Set task priority:
  - High
  - Normal
  - Low
- Filter tasks:
  - All
  - Active
  - Completed
- Clear all completed tasks
- Automatic task completion percentage
- Progress indicator
- Current date display
- Tasks are saved using `localStorage`
- Press **Enter** to quickly add a task
- Smooth animations and hover effects
- Responsive design for different screen sizes
- No page scrolling on desktop
- Interactive animated **Digital Check-In** heading

## Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling, layout, animations and responsive design
- **JavaScript** – Task management and DOM manipulation
- **LocalStorage** – Saving tasks in the browser
- **Google Fonts** – DM Sans and Playfair Display

How to Run
Download or clone the project.
Open the project folder.
Open index.html in any modern web browser.

No server or additional installation is required.

How It Works
Adding a Task

Enter a task in the input field, select its priority, and click Add Task.

You can also press Enter to add it quickly.

Completing a Task

Click the circular button beside a task to mark it as completed.

The completion percentage updates automatically.

Editing a Task

Double-click the task name to edit it.

Filtering Tasks

Use the filters at the top of the task section to display:

All tasks
Active tasks
Completed tasks
Saving Tasks

Tasks are stored using the browser's localStorage, so refreshing the page does not remove them.

Design

The interface uses a dark navy theme with lavender accents and subtle animations.

The main heading uses a different font style and animated movement to give the application a more distinctive visual identity.
